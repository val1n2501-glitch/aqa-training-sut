# Этапы обучения Python AQA

Подробные уроки, задания и прогресс находятся на Course Site. ChatGPT Project помогает как персональный наставник. SUT служит приложением под тестирование, а student repository содержит собственную автоматизацию ученика.

| Дни | Этап |
|---|---|
| 1–14 | Python Core |
| 15–20 | Проект, окружение, файлы, конфигурация, Python для QA и основы SQL |
| 21 | Первый pytest-тест |
| 22–29 | pytest, фикстуры, параметризация и архитектура |
| 30–39 | API |
| 40–51 | Playwright |
| 52–57 | Git, архитектура, отчёты, параллельный запуск и CI |
| 58–60 | README, портфолио, резюме, защита и итоговая проверка |

На этапе дней 15–20 познакомьтесь с запуском SUT и его интерфейсом. Далее используйте [API-контракт](api-contract.md) как спецификацию, а задания берите на Course Site. Тесты и их архитектуру разрабатывайте самостоятельно в своём репозитории на основе [student template](https://github.com/val1n2501-glitch/aqa-automation-student-template).

Технический smoke самого SUT подтверждает его доступность и не является готовым проектом автоматизации ученика. В итоговом README укажите версию SUT, свой вклад, способ запуска и результаты собственных проверок.
