# Идея bug lab

Bug lab — будущая отдельная лаборатория для поиска и описания дефектов. Основная версия SUT остаётся рабочим учебным стендом без намеренно внесённых ошибок.

Если лаборатория будет подготовлена, её версии будут явно отделены от стабильного SUT и обозначены в заданиях Course Site. Сейчас этот документ описывает концепцию и не обещает наличие отдельных веток или сборок.

Работа ученика в такой лаборатории: исследовать поведение по спецификации, воспроизвести наблюдаемую проблему, собрать достаточные доказательства и оформить понятный баг-репорт. Набор намеренных дефектов и готовые решения не входят в публичную документацию стенда.

Для обычной практики используйте стабильную версию SUT и [API-контракт](api-contract.md).
