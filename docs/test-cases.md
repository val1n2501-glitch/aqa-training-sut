# Направления самостоятельного тестирования

Составьте собственный план по [API-контракту](api-contract.md), интерфейсу приложения и заданиям Course Site. Для каждого выбранного риска определите цель проверки, необходимые данные, действия и ожидаемый результат, затем обоснуйте приоритет.

Темы для исследования:

- Жизненный цикл задачи и согласованность API с интерфейсом.
- Границы входных данных и обработка некорректных запросов.
- Поиск, фильтры, сортировка и навигация по списку.
- Сохранение данных и независимость тестовых запусков.
- Пользовательские сообщения, формы и подтверждения действий.
- Доступность служебных возможностей в разных режимах приложения.

Решите, какие проверки относятся к API, какие требуют браузера, а какие полезнее выполнить вручную. Подберите собственные данные и способ подготовки окружения. Реализация тестов, фикстур и организации проекта — часть вашей работы в student repository.

Этот документ задаёт направления; конкретные задания и критерии оценки находятся на Course Site.
